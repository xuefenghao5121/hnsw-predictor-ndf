**关键变化**: 
1. 新基线 24T=19766 超过旧基线 16T=18044 成为 peak
2. 1T/4T 提升 ~12-15% (FVC 64→160 收益)
3. 12T+ 变化不大 (WILLNEED 锁竞争主导，FVC 不是瓶颈)

## 观察

1. **512MB peak 从 16T 移到 24T**: 新基线 24T=19766，可能因 FVC=160 缓存更多向量
2. **256MB 12T 后进入平台**: 10K-11K QPS，file cache 已极度紧张 (43→19MB)
3. **1T 比值稳定 81%**: WILLNEED 在低并发下有效弥补 page cache 不足
4. **4T+ 比值 55-64%**: page cache 成为瓶颈，256MB 下 file cache 仅 512MB 的 1/5-1/6
5. **256MB 内存效率最高**: QPS/MB 42.7 vs 512MB 38.6 vs hnswlib 51.3
6. **recall 全程 95.75-95.80%**: cgroup 不影响正确性
