## 无 cgroup vs 严格 cgroup QPS 对比

| Config | 无 cgroup 1T | 严格 256MB 1T | 倍率 |
|--------|-------------|--------------|------|
| M=16 EF=60 | 3,855 | 237 | 16.3x |
| M=24 EF=60 | 3,492 | 237 | 14.7x |
| M=16 EF=80 | 3,117 | 180 | 17.3x |

无 cgroup 高估 14-17x，与 CON-HONEST-002 记录的 1.73-7.60x 一致（高 EF 下 I/O 更多，cache 依赖更强）。

## 核心发现

### 1. DiskHNSW 独有链条在严格测试下更强

M=24 EF=60 vs M=16 EF=80:
- 无 cgroup 1T: +12% → 严格 256MB 1T: **+31.6%**
- 无 cgroup 16T: +15.9% → 严格 256MB 16T: **+37.1%**

原因：cgroup 限制 page cache 后 I/O 成为更大瓶颈，EF↓ 减少 I/O 的价值放大。

### 2. M=24 EF=60 recall 在所有条件下达标

96.60% 在 1T 和 16T 下一致（不随线程数变化），稳过 95%。

### 3. 无 failcnt / OOM

所有配置 cgroup 统计中无 memory violation，RSS ≤ 251MB < 256MB 限制。
